# 从资料创建设计

登录工作台，在左侧打开“📎 从图片或文件创建设计”，上传资料，检查提取参数及其来源，修改实际尺寸，勾选确认后生成。生成使用原来的计费、几何检查和 STEP/STL 下载流程；提取资料本身不创建服务订单。当前仍仅支持双探头平面安装板，不能将任意机械零件自动还原成 CAD。

支持单文件最多 5 MB：

- PNG/JPG：预览图片、手动补齐尺寸；站长启用视觉模型后可点击识别。图片最大 1600 万像素。
- PDF：最多 10 页，未加密，提取可读取的文字及明确尺寸。扫描 PDF 请将页面导出成 PNG/JPG；当前没有本机 OCR。
- TXT：UTF-8 编码，例如“长100、宽45、厚5、孔距50、孔径16.5毫米”。
- JSON：字段名使用现有建模参数，可从网页下载示例；支持只提供部分参数。数值默认毫米，也支持 "14cm" 字符串。
- CSV：两列 parameter,value，每行一个参数；数值默认毫米，开关使用 true/false。例如 length,140。

未识别参数以“推荐值 · 资料未提供”标记，不会声称是客户提供的尺寸。图纸照片没有标注单位、厚度或尺寸时，需要用户补齐，不能从照片比例推导实际尺寸。

上传原件保存在当前服务器会话内，不写入项目目录。退出、切换账户或开始新设计会清除上传状态。含文字文件本地处理；只有用户勾选发送图片的同意选项并点击识别后才会将图片发送到模型服务商。生成模型后，确认后的尺寸会写入现有服务订单描述。

视觉 API 使用已有服务器设置 OPENAI_API_KEY、OPENAI_BASE_URL、OPENAI_MODEL、AICAD_API_PROTOCOL。需要模型及接口支持图片和 JSON 输出。管理员登录后可以尝试；普通演示用户须由站长明确开启 AICAD_ALLOW_DEMO_API=true，默认关闭。公开免费入口禁止图片 API。识别可能消耗站长的真实额度，目前不扣用户演示余额，每个浏览器会话最多 5 次，并受服务器全局体验限额与并发保护约束。此限制不等于真实付费额度管理。

API 协议参考：[OpenAI 官方图片输入文档](https://developers.openai.com/api/docs/guides/images-vision)。已用模拟 SDK 验证两种协议的请求格式；未配置真实视觉模型，因此尚未完成真实图片识别端到端验证。

已安装 pypdf 解析 PDF；云部署时需同步上传新的 requirements.txt、attachment_input.py 与 attachment_ui.py。当前不支持 DWG/DXF/STEP/STL 导入重建、语音和视频输入。
