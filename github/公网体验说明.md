# 免费公开体验入口

`public_app.py` 是免登录体验入口，保留描述尺寸、示例建模、参数修改、三维预览和 STEP/STL 下载。不会显示账户、管理员、演示收费页面，也不会读取或调用站长 API。`app.py` 继续保留本机管理和演示计费。

## 现在分享

双击 `发布体验链接.cmd`，程序启动本机 8502 端口的公开入口，建立 Cloudflare Quick Tunnel，并显示实际 HTTPS 链接。链接经过健康检查才报告已就绪。把该链接发给他人即可使用，无需安装软件或 GitHub 登录。

当前链接同时保存在 `outputs/public_tunnel.json`。正常再次启动会复用仍运行的通道。电脑关机、断网或停止通道时链接失效；重建通道可能产生新链接。Quick Tunnel 用于临时体验，没有永久可用或稳定域名保证。

需要关闭公开访问时，双击 `关闭公网链接.cmd`。仅停止本项目的公网通道，不停止本机管理员网站。停止前会核对进程路径和公开端口，避免误停止其他程序。

本机管理员入口：http://127.0.0.1:8501。
本机公开体验入口：http://127.0.0.1:8502。
不要把这两个本机地址直接分享给外部用户。

## 限额和数据

公开入口每个浏览器会话最多 10 次请求；全站默认每天 100 次（UTC），可以通过服务器环境变量 `AICAD_PUBLIC_DAILY_LIMIT` 调整。失败请求也占用次数。刷新/重新连接可能创建新会话，因此会话限额不作为可靠的用户身份认证；全站限额用于保护整体资源。

同一个 Python 服务进程一次只进行一项建模，忙时请求返回可重试提示。未来多进程/多服务器部署应改为统一任务队列。每日计数保存在 `outputs/public_usage.sqlite`，不保存访客描述。模型文件仍在服务器 `outputs` 目录，不提供公开目录列表，访客应及时下载成果。

当前支持双探头平面安装板；其他零件类型和任意机械装配尚未支持。重量为估算，承载性能没有验证。

## 长期公网托管

临时链接需要本机保持运行。如果希望电脑关机后大家仍能用，需要将新版源代码部署到云服务器或 Streamlit Community Cloud，并以 `public_app.py` 为入口。指定 Python 3.12，仓库根目录放 `packages.txt`，requirements.txt 与入口放在同一目录。当前 GitHub 仓库仍是旧版，必须上传新版文件后再部署。

公开入口不使用真实 API，无需配置 API 密钥。平台隐私设置应设为 Public。云端部署成功后，应重新测试健康接口、浏览器资源、WebSocket、建模与 STEP 下载，再分享实际平台分配的地址。

## 官方工具

临时通道客户端：Cloudflare cloudflared 2026.9.3，使用官方 Windows x64 文件并校验 SHA-256，保存在 `.local-tools/cloudflare/cloudflared.exe`。源码包不会包含该客户端；另一台机器使用临时通道时需要从 Cloudflare 官方渠道下载对应文件。没有安装系统服务或开机启动项。

- https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/
- https://github.com/cloudflare/cloudflared/releases/tag/2026.9.3

# 登录版公网地址

完整登录网站使用 `发布登录网站.cmd` 发布，通道指向本机 8503。访客可注册后使用附件和 CAD 工作台；管理员账号沿用本机账本。用 `关闭登录公网链接.cmd` 关闭该通道，不影响原来免登录体验版。

这是临时 HTTPS 地址，电脑需保持开机联网。关闭或重建通道可能更换网址，不能当作已完成长期云托管。计费仍是演示，真实收款尚未启用。
