# 多厂商 AI 接入

## 用户选择 API 来源

工作台选择“在线模型 API”后，可以选择“使用站内 API”或“使用自己的 API”。自带 API 用户填写服务商、实际模型 ID 和密钥，并勾选服务器调用授权。用户密钥仅保存在当前会话，不写入配置、账本、聊天或日志；退出/超时/切回站内来源会清除。支持预设官方服务商，不接受访客任意指定网络地址。图片识别沿用同一来源，并单独要求图片发送同意。

自带 API 的模型费用由用户供应商账户承担，本站 CAD 服务仍按现有演示价格计费，失败退回。普通演示账户暂不能使用站长真实额度；充值中心明确标记“待开发”，按钮禁用，不会收款、添加余额或创建支付订单。站内额度开放及真实支付需要后续明确配置。

管理员后台已提供供应商选择：OpenAI、DeepSeek、阿里百炼/千问、Google Gemini、火山方舟/豆包、硅基流动，以及其他 OpenAI 兼容接口。每个供应商分别配置密钥和模型，不会把一家密钥自动拿给另一家使用。访客不能切换供应商或查看密钥。

## 本机配置

1. 在对应厂商账户开通 API，确认可用模型及余额。网页聊天会员不代表已开通 API。
2. 双击 `配置AI接口.cmd`，选厂商，填写实际模型 ID 和接口根地址，密钥在本机终端输入且不回显。界面支持多次运行，分别保存各家配置。
3. 配置写入 `.streamlit/secrets.toml`，已排除 Git 和 Docker 打包；不要把这个文件上传公开仓库，也不要在聊天发送密钥。若服务已运行，重启登录网站或重新加载服务端配置。
4. 登录管理员后台，在“AI 接入状态”选择并切换对应供应商。
5. 返回工作台选择“在线模型 API”，先验证小型文字需求，再单独验证图片。普通演示用户默认不允许消耗站长真实 API，管理员可以验证自己的 API；开放普通账户须在服务端明确设置 `AICAD_ALLOW_DEMO_API=true`。

工具适配与真实调用是不同的验收：目前配置及模拟 SDK 测试已完成，尚没有用户的有效 API，因此不能宣称各平台已实际调用成功。模型必须支持工具调用，图片识别还需支持视觉输入和 JSON 输出。主入口选择对应 CAD 工具，严格检查参数，再由 CadQuery 生成模型；不会运行模型编写的任意 Python。

## 环境变量

每家使用独立前缀，分别设置 `{前缀}_API_KEY`、`{前缀}_MODEL`、`{前缀}_BASE_URL`、`{前缀}_PROTOCOL`：

|厂商|前缀|
|---|---|
|OpenAI|OPENAI|
|DeepSeek|DEEPSEEK|
|百炼/千问|QWEN|
|Gemini|GEMINI|
|豆包|DOUBAO|
|硅基流动|SILICONFLOW|
|其他兼容接口|CUSTOM_AI|

默认采用 Chat Completions；只有支持 Responses 的服务可改协议。`AICAD_API_PROVIDER` 提供初始供应商，后台已保存的选择优先。云平台把密钥配置到服务端环境变量，不使用本机配置文件上传。

官方接口预设需要按账户地区、工作空间和套餐核对，模型名需填写实际可用 ID，没有自动购买或充值。原生 Anthropic、以及不兼容 OpenAI 的服务目前未实现专用适配；自定义入口不能将任意协议转换成兼容接口。

官方参考：[DeepSeek](https://api-docs.deepseek.com/)、[百炼兼容接口](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)、[Gemini 兼容接口](https://ai.google.dev/gemini-api/docs/openai)、[豆包文本接口](https://docs.volcengine.com/docs/ark/text-generation?lang=zh)、[硅基流动](https://api-docs.siliconflow.cn/docs/userguide/quickstart)。

## 当前 CAD 能力

支持双探头平面安装板和带盖长方体盒子。用户原案例“长150mm宽140mm高100mm厚2mm，有盖子”对应两个实体，闭合装配外高包含盖板；不会添加探头孔。盖子定位唇、0.3mm 每侧间隙和6061铝重量估算均为建议，不是用户提供的加工条件。

API 接通不等于任意零件都能生成；未支持结构应说明并询问，不能将其套成另一种零件。更复杂零件需要继续实现结构特征及验收案例。
## 站内多模型选择与 Kimi

工作台选择“在线模型 API → 使用站内 API”后，“站内 AI 模型”列表显示服务端已配置的厂商。现在已支持 Kimi / 月之暗面，官方地址为 `https://api.moonshot.cn/v1`。

Kimi 使用独立的 `KIMI_API_KEY`、`KIMI_MODEL`、`KIMI_BASE_URL` 和 `KIMI_PROTOCOL`，与 DeepSeek 密钥隔离。当前已实际验证 `kimi-k2.6` 能把 150 × 140 × 100 mm、壁厚 2 mm 的带盖盒子描述转换为 CAD 参数并导出 STEP。此测试不代表任意零件或图片需求均已验证。

后续双击“配置AI接口.cmd”，配置厂商、实际模型 ID 和密钥，再重启网站；完整配置会自动加入用户可选列表。管理员后台的厂商切换用于设置默认选项。每个厂商目前提供一个配置模型；多个同厂商模型的独立目录尚未实现。

站内模型选择不会解除普通演示账户的 API 额度限制，充值和真实支付仍未开放。不要把密钥写入公开仓库或聊天记录。
