# TRIZ AI CAD 本地网站

1. 双击项目目录中的 `启动网站.cmd`，等待浏览器打开。
2. 网站地址是 http://127.0.0.1:8501，只能在运行它的这台电脑使用。
3. 在左侧注册并登录，确认单次演示服务费，再点击“标准支架”生成第一个模型。可以拖拽旋转、滚轮缩放。
4. 在对话框输入“长度改为140，关闭减重”，其他尺寸会保留。
5. 右侧“尺寸编辑”页签可直接填写数值，点击“应用尺寸并生成”。
6. “TRIZ 与检查”页签显示减重原理、计算基准与检查范围。
7. 下载 STEP 文件导入支持 STEP 的 CAD 软件，或下载 STL 网格文件。

默认本地模式无需密钥和互联网，但只识别明确尺寸与开关。
在线模式可选择站内模型或用户自己的 API。站内调用默认只向管理员开放；管理员可以为指定账户开通试用，试用会消耗站长真实模型额度。用户自带 API 的模型费用由对应厂商收取。
当前支持双探头平面安装板、中央圆头减重槽、边缘倒角，以及带独立盖子的空心盒。
重量按 6061 铝密度估算，不代表应力、强度或疲劳性能已经验证。

网站由本机运行，关闭浏览器不停止后台服务；电脑重启后再次双击启动入口。
如果已经打开旧版本页面，刷新浏览器即可查看更新后的界面。
GitHub 和云端发布可以之后单独处理。

“服务订单”页签查看自己的订单。默认 ¥1/次为演示价格，不收取真实款项。
需要查看全站统计时，双击 `设置管理员.cmd` 创建站长账户，再登录网站。
详细配置见 `经营与计费说明.md`。

## 项目、附件与账户管理

- 生成后在“我的项目”命名保存。下次登录可打开、重命名或删除记录；保存和打开不会重新调用 API 或扣演示余额。
- 每个账户最多保存 50 个项目。同一订单重复保存只修改名称；重新生成的版本可另存一个项目。
- 下载“参数 JSON”可作为附件重新导入；“设计报告”包含真实几何计算和参数。重复下载免费。
- 附件区支持选择安装板或带盖盒子，并提供两类参数示例。图片没有可用的识别结果时，仍可手动选择类型和填写尺寸；没有单位或缺失的尺寸需用户确认，不能保证由照片重建任意零件。
- 项目记录依赖服务器数据库，模型依赖服务器输出文件。删除项目只删除库中记录，不删除订单和原模型；模型文件丢失时可以下载参数，重新生成将创建新订单。
- 账户侧栏可修改密码，需填写旧密码和确认新密码。其他已登录会话在下次交互时退出；邮件找回密码尚未接入。
- 管理员入口为网站地址加 `?page=admin`。可按用户名查询、查看厂商配置、调整演示报价与每日限额，并对指定账户开启或关闭站内 API 试用。
- 未接真实支付，不可付款、充值或把演示记账当作真实收入。当前临时公网链接依赖本机运行，正式托管参见“正式网站部署说明.md”。
