# TRIZ AI CAD 按次服务与经营

当前完成的是账户、演示计费、订单记录与经营统计。支付平台未接通，不会收到真实款项，不能将演示服务费当作营业收入。默认单次价格为 ¥1（演示推荐值，可修改），每个新账户获得 ¥10 演示额度。

## 使用

1. 双击 `启动网站.cmd`，打开 http://127.0.0.1:8501。
2. 在左侧注册客户账户，登录并确认单次价格。
3. 每次成功生成模型扣一次演示服务费，修改后重新生成也计一次。
4. 建模错误或 API 失败退回预占额度，查看和下载已有成果不计费。
5. 右侧“服务订单”页签查看自己的订单和 CSV 导出。

## 管理员

双击 `设置管理员.cmd`，按提示设置用户名与密码。密码至少 10 位，输入不回显。不要在普通注册页面注册同名账号，普通注册不会获得管理员权限。

使用管理员账号登录后，在“服务订单”页签中可以查看客户数、成功/失败/处理中订单、演示服务费累计和真实到账收入。管理员可以修改单次价格、单用户每日限额、导出全站最近 500 笔订单。全站统计聚合全部历史订单，导出仅限最近 500 笔。当前真实到账收入始终为 0。

金额以整数分存储，历史订单保留当时的价格。价格变更后需要重新确认新价格。每日限额使用 UTC 日历日，失败请求也计入限额，默认每用户 20 次、全站 100 次。

账户、加盐密码哈希和订单保存在 `outputs/business.sqlite`。原始密码不存储，模型/API 密钥不进入订单。模型文件仍保存在 `outputs`，备份时应同时备份数据库和模型，注意访问权限。普通客户看不到全站订单，退出/切换账号会清除当前页面模型与聊天。

服务器如果在建模过程中意外退出，订单可能停留在“处理中”，额度尚未计入成功服务费。当前不自动处理这类中断，不应将此版本用于真实资金结算。

## 使用站长自己的 API            

将 `.streamlit/secrets.toml.example` 复制成 `.streamlit/secrets.toml`，在本机编辑 API 密钥、地址、模型名称。也可以通过服务器环境变量配置同名字段。实际密钥文件已经被 `.gitignore` 排除，不能上传仓库或发送到聊天。

API 配置只在服务器读取，客户界面不再填写或显示站长密钥。模型成本由站长承担。默认 `AICAD_ALLOW_DEMO_API = "false"`，演示额度不能触发付费 API。站长明确将它设置为 `"true"` 后才可在演示中测试真实 API，仍受每日限额控制。真实模型调用尚未验证，因为未提供 API 配置。

`AICAD_BILLING_MODE=demo` 是默认模式；`off` 用于个人本地免费体验。其他模式拒绝启动计费，避免误认为已接入真实支付。

## 接入真实收款还需要什么

需要确认最终单价与微信/支付宝等支付平台，取得商户资格和接口配置。充值或付款必须由服务器校验支付通知签名、商户订单、币种与金额，再幂等入账；不能依据客户点击“已付款”或付款截图自动加余额。当前没有充值按钮和支付成功回调，也没有任何自动收款能力。

公开收费前还需部署到 HTTPS 服务，并使用可靠的持久化数据库、备份、支付对账及退款流程。当前 SQLite 适合本机开发，不能依赖云平台临时容器文件保存真实账本。公开演示注册无手机号/邮件验证，演示额度不适合公开消耗真实模型额度。

可以将该产品经营为收费 CAD 服务，但实际利润取决于需求、服务价格和成本：

净收益估算 = 真实已结算服务收入 − API 成本 − 托管成本 − 支付手续费 − 退款及其他经营支出。

本版本不提供真实利润数字。需遵守所用 API 服务商的商用条款与各依赖许可证；发布前还需核查实际经营地区和支付商户的经营、税务与客户退款要求。
